# Style Guide

Status: creative decisions await visual review. This is not an approved channel style.

Milestone 0 uses only an SVG circle and two fixed smoke colors: `background`
(`#102030`) and `accent` (`#f0a040`). They are renderer-local test constants, not
an asset registry or production theme. No rendered text or external fonts are used.

Before serious animation work, review palette, outlines, typography, character
proportions, spacing, safe areas, and the other requirements in handoff §14.
Do not promote the smoke colors into approved style decisions automatically.
